# Mostra Amazônia Criativa

Site da mostra de projetos da disciplina **Programação Web para Jogos**, desenvolvido por alunos do Curso Técnico em Programação Web para Jogos.

## Acesse o site

Visite a página publicada no GitHub Pages:

**[profaluanaleal.github.io/Projetos_web_jogos](https://profaluanaleal.github.io/Projetos_web_jogos/)**

## Sobre o projeto

O site reúne jogos e experiências interativas inspirados na Amazônia, combinando tecnologia web, biodiversidade, cultura regional, mitologia e consciência socioambiental.

Cada cartão apresenta a proposta do jogo, suas mecânicas, controles e um link para jogar na plataforma correspondente.

## Projetos apresentados

- **Aventura no Rio Amazonas**: corrida de reflexos em um cenário fluvial.
- **Flying Over Amazonas**: jogo de voo sobre o dossel da floresta.
- **Rio Vivo**: experiência educativa de preservação dos rios.
- **Lendas da Amazônia**: aventura inspirada no folclore amazônico.
- **Transamazônica Rally**: corrida off-road pela Rodovia Transamazônica.
- **Fruit Bubble**: jogo arcade de combinação de frutas.
- **Amazônia Quiz**: quiz sobre fauna, flora, povos originários e ecossistemas.

## Tecnologias

- HTML5
- CSS3
- Canvas API, nos jogos que utilizam gráficos interativos
- GitHub Pages para publicação

## Estrutura

```text
.
├── index.html                 # Página principal da mostra
├── style.css                  # Estilos e layout do site
└── .github/workflows/pages.yml # Publicação automática no GitHub Pages
```

## Publicação

O site é publicado automaticamente pelo GitHub Actions sempre que há um novo push na branch `main`.
